# AWS EC2 Website

A basic HTML website deployed on an Amazon EC2 instance using Apache.

## Live Website
http://54.206.82.60

## What I did
- Learned IAM users, groups, roles, policies and least privilege
- Launched an EC2 instance (Amazon Linux 2023, t3.micro)
- Configured a Security Group (SSH and HTTP)
- Installed Apache (httpd) web server
- Deployed index.html to /var/www/html

## Tech
AWS EC2, IAM, Apache, HTML
